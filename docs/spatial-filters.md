# GaussianBlur 与 filter2D

两种接口接受调用方的输入、输出和系数缓冲区。每个 GpuMat 是独立有效区域。
输入和输出可以有不同的字节行距。两者的像素不能重叠。卷积邻域只读取
视图内的像素，等同于 OpenCV 的 BORDER_ISOLATED。边界支持 CONSTANT（零）、
REPLICATE、REFLECT 与 REFLECT_101。调用在给定原生流上提交。

## 准备与执行

- 构造 GaussianPlan 或 Filter2DPlan。将 table() 返回的字节上传到 double 对齐的
  设备分配。保留计划直到上传完成。
- 传入 DeviceWorkspace。保持系数只读且与图像分离，排序上传与所有读取流。
  保持设备分配及流直到最后一次调用完成。
- GaussianBlur 的两 pass 重载另外接受可写 GpuMat。尺寸和通道与输入相同，
  深度由 scratch_depth() 返回。中间图与输入、输出和系数表分离。
  两个 kernel 在同一流内顺序执行。调用方管理中间图和全部分配。

GaussianBlur 支持 U8、U16、F32、F64 与 1–4 个交错通道。尺寸可显式指定为
正奇数，也可在 sigma 为正时通过非正轴尺寸启用自动推导。
非正的 sigma_y 继承 sigma_x。非 CONSTANT 边界模式的单像素轴可折叠。
轴宽最大 65535，较大的核仍走通用循环。
U8/U16 每个轴分别量化为 8/16 位小数，使用误差扩散和中心残差保持归一。
等宽高的核在有效 sigma 相差小于 binary64 epsilon 时共用横向系数。
U16 的横向累加用 U32，纵向用 U64。整数仅在末端执行半向上舍入。

filter2D 做相关。系数按行排列，默认锚点为核中心，两轴可以独立指定。
输出深度默认为源深度。U8 可以输出 U8、U16、S16、F32 或 F64。
U16 和 S16 各可输出同深度、F32 或 F64。F32 与 F64 也各自支持同深度。
当前通用直接相关在输出为 F64 时用 F64 工作精度，其余用 F32。
它先加入 delta，再按行顺序累加非零权重，禁用乘加融合。
整数输出先按最近偶数转换到有符号 i32，再饱和到目标深度。
固定 SSE3 OpenCV 的无效 i32 转换结果为 INT_MIN。
全零核保留左上角的零 tap，使该位置的非有限输入按固定 CPU 传播。

## 数值范围与性能验证

固定参考是 OpenCV 5.0.0 SSE3 的 CPU 实现，分别用 CPU 输出核对准备系数和 GPU 执行。
整数逐字节比较。F32/F64 有限输入测试使用逐元素误差上限
2e-5 × max(1, abs(ref)) 和 4e-12 × max(1, abs(ref))。
四个中心 `0.5` 的整数专项用例按[半权专项参考](numerical-tolerance.md#filter2d-半权专项参考)
逐位验证。固定 CPU 其它路径的差异按输入和布局单独取证。

固定 CPU 的同深 C1 大核在隔离视图上按核面积进入 DFT，8U 的阈值是 130，
16U 是 50。对 16U，CPU 把有效系数转成 F32，频域相关用 F64，裁切后按
`convertTo` 转成目标整数。`abs(delta) < DBL_EPSILON` 时使用无缩放转换，
SIMD 与标量均直接舍入 F64 源值。带缩放转换按实际 DFT 块的转换宽度选路径。
从 8 个元素起，SIMD 先窄化 F64 源值，再以 F32 加上 `float(delta)`。
最后一组可以回退到末尾 8 个元素，与上一组重叠。短于 8 的块使用
F64 源值和转换后的 `float(delta)`，再执行标量舍入。

核宽为 `K`、图像宽为 `W` 时，内部块宽先取
`g = min(W, max(cvRound(4.5 * K), 257 - K))`。变换宽取
`F = max(2, getOptimalDFTSize(g + K - 1))`。有效块宽为
`B = min(W, F - K + 1)`。最后一块使用剩余宽度。`K=1` 的裁切块可能连续，
源和目标块均连续且展平长度小于 `INT_MAX` 时，`convertTo` 合并各行。

19×37 U16C1 视图取值 65535 时，两组相消用例在 7×7 核返回 0，
在 9×9 核分别返回 3 和 4。9×9 中心半权核、输入 65533 与 `delta=1e-4`
的控制在 1×7 和 1×8 分别返回 32767 和 32766。较大整数核的生产修正及
其它深度、通道与布局的完整验证仍待实测。

Gaussian 的小核可用单次提交。较大核的两 pass 路径由调用方提供中间图。
C++ 计时包括所有提交、同步及中间图流量，分配与表上传单计。
在 gfx936 上，实测 F32 C3 相关的 128 元素 tile 使用两个 wave。
通用 kernel 和其它类型或平台仍由原计划选择配置。

HIP 测试目标是 flagcv.hip.spatial_filters。其测试程序还提供
`--gaussian-boundary` 和 `--benchmark` 分别复验舍入边界与选定公开调用的同步 wall。
`--filter2d-half-reference` 复验四个半权配置的奇偶输入。
`--filter2d-three-tap-reference` 验证 16U 的三系数半步舍入、极值、单轴和行距。
`--row-pair` 校验行复用和窄化为零的系数回退。

gfx936 的 F32 C3 同深输出在 REFLECT_101、宽至少 256、高至少 128、
核两轴为 3–9 时可共用相邻输出行的源像素加载。每项提交的系数绝对值须
达到最小正常 F32，避免与直接路径的零权重跳过行为发生差异。
每个输出在 delta 后按原 tap 顺序累加。奇数高度的末行独立写入。
其余系数、形状及设备使用直接计算。

SM90 对同深 F32 C4、REFLECT_101 和 7×7 非全零核的相关，宽至少
1920 且高至少 1080 时，整块在有效范围内的像素使用连续源地址。
边缘块保留同一反射和零系数规则。其它形状和目标使用直接计算。
